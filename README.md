# Kalkulator Nilai responsi PBW2

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000.

The mobile-friendly wireframe UI uses locally bundled Wired Elements and Patrick Hand; no installation or internet connection is required. Asset sources and licenses are in `vendor/README.md`. Native controls remain available if the sketch library cannot load.

Grading uses three levels (0, 1, 2), with points calculated as `weight × level / 2`. Draft saving, reset, and Markdown export are included.

Run scoring/export tests with `node --test rubric.test.js`.
