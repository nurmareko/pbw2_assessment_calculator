# Project context

This is an instructor-facing PBW2 verbal-assessment calculator, not a student solution. Preserve the supplied PDF's rubric weights. The PDF does not prescribe a numerical coding/verbal split; clearly label any proposed scoring scale as an instructor aid, not official policy. Do not publish the assessment PDF.

## Minimal UI Rules
The user explicitly replaced the wireframe direction with a minimal utility. Use plain HTML inputs/selects, system fonts, a white background, simple dividers and compact responsive rows. No external UI libraries, web fonts, sketch effects, decorative icons, marketing sections or animations. Keep the main workflow to student identity, rubric ratings, weighted total and reset. Preserve accessible labels and visible keyboard focus.
